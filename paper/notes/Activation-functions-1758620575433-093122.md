# Activation functions

## Introduction
In the realm of Artificial Neural Networks (ANNs), **activation functions** are critical components that determine the output of a neuron, acting as decision-making gates [GFG5]. They introduce non-linearity into the network, enabling it to learn and model complex patterns beyond simple linear relationships [GFG1], [GFG5]. This document explores the definition, importance, various types, and impact of activation functions on neural network performance.

## TL;DR
*   **Activation functions** decide if a neuron "fires" and determine its output [GFG3], [GFG5].
*   They introduce **non-linearity** to neural networks, which is essential for learning complex patterns [GFG1], [GFG5].
*   Without activation functions or with only linear ones, a neural network can only model linear relationships [GFG1], [GFG5].
*   Common **non-linear activation functions** include **Sigmoid**, **Tanh**, **ReLU**, **Leaky ReLU**, **ELU**, **Swish**, and **Softmax** [GFG1], [GFG3], [GFG4], [GFG5].
*   **Sigmoid** and **Tanh** are S-shaped, outputting between [0,1] and [-1,1] respectively, but are prone to the **vanishing gradient problem** [GFG1], [GFG3], [GFG4].
*   **ReLU** is popular for its computational efficiency and ability to mitigate the **vanishing gradient problem**, but can suffer from "dying ReLU" [GFG3], [GFG4], [GFG5].
*   **Leaky ReLU** and **ELU** address the "dying ReLU" problem by allowing a small or exponential output for negative inputs [GFG3], [GFG4], [GFG5].
*   **Softmax** is typically used in the output layer for **multi-class classification** to convert outputs into probabilities that sum to 1 [GFG1], [GFG3], [GFG4], [GFG5].
*   The choice of activation function directly impacts **convergence speed** and overall model performance [GFG1].

## What are Activation Functions?
An **activation function** is a mathematical formula that takes the input to a neuron, performs a calculation, and then produces an output, effectively deciding whether a neuron should be activated or not [GFG5]. In Artificial Neural Networks (ANNs), activation functions are considered building blocks [GFG3].

## Why are Activation Functions Important?
Neural networks consist of neurons that operate using **weights**, **biases**, and **activation functions** [GFG1]. During the learning process, these **weights** and **biases** are updated based on the error produced at the output [GFG1]. The primary reasons for their importance are:

*   **Introducing Non-Linearity**: Without activation functions, or if only linear activation functions were used, a neural network would only be able to learn **linear relationships** [GFG1], [GFG5]. The relationship between input and output would be a straight line, meaning the output would not change proportionally with the input [GFG1]. This limitation means the network could not handle more complex problems [GFG5].
*   **Enabling Complex Pattern Learning**: The inclusion of a non-linear activation function, such as **ReLU**, allows the network to introduce a **non-linear decision boundary** in the input space [GFG1]. This **non-linearity** is crucial as it enables the network to learn more intricate and complex patterns present in the data [GFG1], [GFG5].
*   **Overcoming Limitations of Linear Models**: Even with multiple layers, a neural network using only linear activation functions would still produce an output that is merely a linear combination of its inputs. This effectively makes a multi-layer network behave like a single-layer network, losing its ability to model non-linear data [GFG1].

## Types of Activation Functions
Several different types of activation functions are used in Deep Learning, categorized primarily into linear and non-linear types [GFG1], [GFG2]. Frameworks like PyTorch and TensorFlow provide implementations for many of these [GFG3], [GFG4].

### Linear Activation Function
A **Linear Activation Function** resembles a straight line, defined by the equation `y=x` [GFG1].
*   **Characteristics**:
    *   Output is directly proportional to the input.
    *   No matter how many layers a neural network contains, if they all use linear activation functions, the output remains a linear combination of the inputs [GFG1]. This limits the network's ability to learn complex, non-linear patterns [GFG1].

### Non-Linear Activation Functions
Non-linear activation functions are essential for neural networks to learn complex relationships [GFG1].

#### Sigmoid Function
The **Sigmoid Activation Function** is characterized by an 'S' shape [GFG1].
*   **Formula**: `A = 1 / (1 + e^-x)` [GFG1], `σ(x) = 1 / (1 + e^-x)` [GFG2], [GFG5].
*   **Characteristics**:
    *   Produces a smooth and continuous output [GFG1].
    *   Output values range between 0 and 1 [GFG1], [GFG3], [GFG4], [GFG5].
    *   Non-linear and differentiable [GFG3].
    *   Does not pass through the origin [GFG3].
    *   Often used in **binary classification problems** [GFG4], [GFG5].
    *   **Disadvantage**: Prone to the **vanishing gradient problem**, especially in deep networks, which can slow down training [GFG1], [GFG4].

#### Tanh (Hyperbolic Tangent) Function
The **Tanh function** is similar to the Sigmoid function in its S-shape but offers a different output range [GFG3], [GFG4].
*   **Characteristics**:
    *   Non-linear and differentiable [GFG3].
    *   Output values range from -1 to +1 [GFG3], [GFG4], [GFG5].
    *   Is **zero-centered**, which often leads to faster convergence during training compared to Sigmoid [GFG5].
    *   Passes through the origin [GFG3].
    *   Better for hidden layers than Sigmoid because it allows for both positive and negative outputs [GFG4].
    *   **Disadvantage**: Still suffers from the **vanishing gradient problem** [GFG4].

#### ReLU (Rectified Linear Unit)
**ReLU** stands for **Rectified Linear Activation function** and is one of the most popular choices in deep learning [GFG3], [GFG4], [GFG5].
*   **Formula**: `ReLU(x) = max(0, x)` [GFG2].
*   **Characteristics**:
    *   A non-linear function [GFG3].
    *   Outputs the input directly if it is positive; otherwise, it outputs zero [GFG4], [GFG5].
    *   Computationally efficient [GFG5].
    *   Helps mitigate the **vanishing gradient problem** and improves training efficiency [GFG4].
    *   **Disadvantage**: Can suffer from the "dying ReLU" problem, where neurons become inactive for negative inputs and stop learning [GFG4], [GFG5].

#### Leaky ReLU
**Leaky ReLU** (LReLU) is a variant of ReLU designed to address the "dying ReLU" problem [GFG3], [GFG4], [GFG5].
*   **Characteristics**:
    *   Similar to ReLU, but allows a small, non-zero output for negative input values [GFG4], [GFG5].
    *   This small gradient prevents neurons from becoming completely inactive [GFG4].

#### ELU (Exponential Linear Unit)
**ELU** is an activation function similar to ReLU, but with an exponential curve for negative values [GFG4].
*   **Characteristics**:
    *   Helps avoid the **vanishing gradient problem** [GFG4].
    *   Demonstrates better performance on deep neural networks [GFG4].
    *   One source lists Softmax under a general category "Exponential Linear Units" [GFG1], though other sources treat ELU and Softmax separately [GFG3], [GFG4], [GFG5].

#### Swish
**Swish** is a newer activation function proposed by Google [GFG4].
*   **Formula**: `f(x) = x * sigmoid(x)` [GFG4].
*   **Characteristics**:
    *   Has shown better performance than ReLU and its variants in many cases [GFG4].

#### Softmax Function
The **Softmax function** is primarily designed for **multi-class classification problems** [GFG1], [GFG4], [GFG5].
*   **Characteristics**:
    *   Transforms raw output scores (known as **logits**) from a neural network into probabilities [GFG1], [GFG4], [GFG5].
    *   The sum of all probabilities for the output classes will equal 1 [GFG4].
    *   Typically placed at the last (output) layer of a neural network [GFG3], [GFG4], [GFG5].
    *   Can be used in combination with other activation functions in earlier layers [GFG3].

## Impact on Model Performance
The choice of activation function has a direct impact on the performance of a neural network in several ways [GFG1]:
*   **Convergence Speed**: Functions like **ReLU** allow faster training by avoiding the **vanishing gradient problem**, which can significantly slow down convergence [GFG1]. **Tanh** can also lead to faster convergence than **Sigmoid** due to being zero-centered [GFG5].
*   **Learning Complex Patterns**: Non-linear activation functions are crucial for the network to learn and represent complex patterns that linear models cannot [GFG1].
*   **Mitigating Problems**: Specific functions like **Leaky ReLU** and **ELU** are designed to overcome issues such as the "dying ReLU" problem, improving network stability and learning [GFG4].

## Choosing the Right Activation Function
The selection of an activation function depends heavily on the specific task and network architecture:
*   **Hidden Layers**:
    *   **ReLU** and its variants (**Leaky ReLU**, **ELU**, **Swish**) are generally preferred for hidden layers due to their ability to mitigate the **vanishing gradient problem** and computational efficiency [GFG4], [GFG5].
    *   **Tanh** can be a good choice for hidden layers, allowing for both positive and negative outputs [GFG4].
*   **Output Layer**:
    *   For **binary classification** tasks, the **Sigmoid** function is suitable as it outputs values between 0 and 1 [GFG4], [GFG5].
    *   For **multi-class classification** problems, **Softmax** is the standard choice, converting outputs into probabilities that sum to 1 [GFG1], [GFG4], [GFG5].

## Examples
### Numerical Calculations
Here are examples of computing outputs for common activation functions:

1.  **Sigmoid Function**: `sigma(x) = 1 / (1 + e^-x)` [GFG2]
    *   For input `x = -1`: `sigma(-1) = 1 / (1 + e^1)` = `1 / (1 + 2.718)` ≈ `1 / 3.718` ≈ `0.269` [GFG2]
    *   For input `x = 0`: `sigma(0) = 1 / (1 + e^0)` = `1 / (1 + 1)` = `0.5` [GFG2]
    *   For input `x = 1`: `sigma(1) = 1 / (1 + e^-1)` = `1 / (1 + 0.368)` ≈ `1 / 1.368` ≈ `0.731` [GFG2]

2.  **ReLU Function**: `ReLU(x) = max(0, x)` [GFG2]
    *   For input `x = -1`: `ReLU(-1) = max(0, -1)` = `0` [GFG2]
    *   For input `x = 0`: `ReLU(0) = max(0, 0)` = `0` [GFG2]
    *   For input `x = 1`: `ReLU(1) = max(0, 1)` = `1` [GFG2]

### Conceptual Examples
*   **Binary Image Classification**: When classifying an image as either "cat" or "dog" (two classes), a **Sigmoid** function would be appropriate for the output layer to produce a probability for one of the classes [GFG4], [GFG5].
*   **Multi-digit Recognition**: For recognizing a handwritten digit (0-9), the output layer would typically use a **Softmax** function to assign probabilities to each of the 10 possible digits [GFG4], [GFG5].
*   **Deep Learning Models**: In deep convolutional neural networks, **ReLU** is a popular choice for hidden layers due to its efficiency and ability to mitigate the vanishing gradient problem [GFG3], [GFG4], [GFG5].

## Common Mistakes
*   **Using Linear Activation Functions in Deep Networks**: Applying only linear activation functions, or none at all, will prevent the network from learning any non-linear patterns, effectively reducing any multi-layered network to a single-layered one [GFG1], [GFG5].
*   **Ignoring Vanishing Gradient with Sigmoid/Tanh**: For very deep networks, using **Sigmoid** or **Tanh** in hidden layers can lead to the **vanishing gradient problem**, where gradients become extremely small, making it difficult for the network to learn effectively [GFG4].
*   **Not Addressing "Dying ReLU"**: When using **ReLU**, failing to monitor for or address "dying ReLU" neurons (where neurons output 0 for all inputs) can lead to parts of the network becoming permanently inactive. Solutions like **Leaky ReLU** or **ELU** can mitigate this [GFG4], [GFG5].
*   **Incorrect Output Layer Activation**: Using **Sigmoid** for multi-class problems (instead of **Softmax**) or **Softmax** for binary problems (when **Sigmoid** is simpler and sufficient) can lead to inefficient or incorrect model outputs [GFG4], [GFG5].

## Memory Aids
*   **S for Sigmoid**: **S**-shaped curve, **S**queezes output to `[0, 1]`, often used for **S**ingle (binary) classification [GFG1], [GFG3], [GFG4], [GFG5].
*   **T for Tanh**: **T**hrough the origin, **T**wo-sided output `[-1, 1]`, generally **T**hought better than Sigmoid for hidden layers [GFG3], [GFG4], [GFG5].
*   **R for ReLU**: **R**ectified means cuts off negative, **R**eally fast computation, **R**isk of "dying" neurons [GFG3], [GFG4], [GFG5].
*   **L for Leaky ReLU**: **L**ets a **L**ittle bit of gradient pass for negative inputs, solving the "dying ReLU" prob**L**em [GFG3], [GFG4], [GFG5].
*   **Softmax for Many**: For **many** classes, **Softmax** converts **many** outputs into **many** probabilities that **sum to one** [GFG1], [GFG3], [GFG4], [GFG5].

## Conclusion
Activation functions are indispensable elements in neural networks, primarily responsible for introducing the **non-linearity** necessary for learning complex data patterns [GFG1], [GFG5]. From the 'S'-shaped **Sigmoid** and **Tanh** functions, with their historical use and gradient challenges, to the widely adopted **ReLU** and its variants like **Leaky ReLU** and **ELU** that address specific training issues, each function offers distinct characteristics [GFG1], [GFG3], [GFG4], [GFG5]. The choice of an appropriate activation function, especially for hidden and output layers, directly influences the network's **convergence speed**, ability to learn, and overall performance in tasks ranging from **binary classification** to complex **multi-class classification** problems [GFG1], [GFG4], [GFG5].
