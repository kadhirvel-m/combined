Chapter One

What is a for loop?

A for loop lets you repeat code for each item in a sequence - like going through a list one by one.

#1

Your First Loop

for i in range(3):
    print("Hello")

Output

Hello
Hello
Hello

The Mental Model

"Imagine a stack of papers. You pick up one paper, read it, put it down, then pick up the next one.

A for loop does exactly that with data: touch each item once.

Chapter Two

The Syntax

for variable in sequence:
# code to repeat
for

Starts the loop

variable

Name for current item

in

Links variable to sequence

sequence

List, range, or string

Mental Model: The Loop Variable

The variable (like i) is just a temporary container that holds a different value each time the loop runs:

Loop 1: i = 0
Loop 2: i = 1
Loop 3: i = 2

You can name it anything: i, x, item, fruit — Python doesn't care!

Critical: Indentation Matters!

In Python, indentation tells Python what code belongs inside the loop. Use 4 spaces (or Tab).

✓ CORRECT

for i in range(3):
    print(i)  # 4 spaces
    print("done")

✗ WRONG

for i in range(3):
print(i)  # No indent!
# IndentationError!

Chapter Three

The range() Function

range() generates a sequence of numbers. It's the most common way to control how many times a loop runs.

THREE FORMS OF RANGE:

range(stop) → 0 to stop-1
range(start, stop) → start to stop-1
range(start, stop, step) → start to stop-1, jumping by step

range(5)

0, 1, 2, 3, 4

range(1, 6)

1, 2, 3, 4, 5

range(0, 10, 2)

0, 2, 4, 6, 8

Chapter Five

                            
Nested Loops

                        

                    

                    
A loop inside another loop. The inner loop runs completely for
                        each
                        iteration of the outer loop.

                    
                    

                        

                            Multiplication Table
                            
                        

                        

                        

                            

                            

                        

                    

                    

                        

                             Warning: O(n²)
                        

                        
Nested loops multiply iterations. A loop of 100 inside another
                            loop of 100
                            = 10,000 iterations. Interviewers watch for this!

Chapter Six

                            
break, continue, pass

                        

                    

                    
Control your loop's behavior with these special keywords.

                    

                        

                            

                                break
                                STOP
                            

                            
Exits the loop immediately. No more iterations.

                            
for i in range(10):
    if i == 5:
        break  # Stops at 5
    print(i)  # Prints 0,1,2,3,4

                        

                        

                            

                                continue
                                SKIP
                            

                            
Skips the current iteration and moves to the next one.
                            

                            
for i in range(5):
    if i == 2:
        continue  # Skip 2
    print(i)  # Prints 0,1,3,4

                        


                    

                    
                    

                        

                            Try break & continue

Chapter Seven

                            
Common Mistakes

                        

                    

                    

                        
                        

                            

                                
                                Off-by-one error
                            

                            
range(5) gives 0 to 4, 
NOT
                                1 to 5.

                            

                                
                                Use range(1, 6) for 1 to 5
                            

                        


                        
                        

                            

                                
                                Modifying List
                            

                            
Never remove items from a list you're
                                currently looping.

                            

                                
                                Use list comprehension instead
                            

                        


                        
                        

                            

                                
                                Missing Colon
                            

                            
The line must ALWAYS end with a colon
                                :

                            

                                
                                for i in range(5):

Solved Problem Walkthrough

                        

                    

                    
Let's solve a real placement-style problem step by step.


                    
                    

                        

                             Problem: Find the Maximum Element
                        

                        
Given a list of numbers, find and return the largest number.

                        
Input: [3, 7, 2, 9, 4] → Output: 9

                    


                    
                    

                        

                            
Step 1: Understand the Problem

                            
We need to compare all elements and track the biggest one
                                we've seen.
                            

                        


                        

                            
Step 2: Plan the Approach

                            
    
                                
  • • Assume the first element is the maximum
    • 
                                
  • • Loop through remaining elements
    • 
                                
  • • If current element > max, update max
    • 
                                
  • • Return max after loop ends
    • 
                            

                        


                        

                            
Step 3: Write the Code

                            

                                

                                    Find Max Code
                                    
                                

                                

                                

                                    

                                    

                                

                            

                        


                        

                            
Step 4: Trace Through

                            

                                
num=3
max=3
                                

                                
num=7
max=7
                                

                                
num=2
max=7
                                

                                
num=9
max=9
                                

                                
num=4
max=9
                                

                            

                            
Green = max updated

                        


                        

                            
Step 5: Complexity Analysis

                            
    
                                
  • • Time: O(n) — we visit each element once
    • 
                                
  • • Space: O(1) — only one variable max_val
    • 
                            

                        

                    


                    

                        

                             Key Takeaway
                        

                        
This pattern — "track the best value while looping" — appears in
                            many
                            problems: find min, find second largest, find first occurrence, etc.
