The Brain’s Sticky Note.

Imagine you are a master chef (the CPU). Your pantry (Hard Drive) is huge but far away. Your fridge (RAM) is closer, but still requires walking.

When you are actively chopping an onion, you don't put it in the fridge between every slice. You keep it on the cutting board right in front of you.

The Register

A Register is the computer's cutting board. It's a tiny, ultra-fast memory slot inside the processor. It holds the number the computer is working on right this microsecond.

Registers are the fastest memory in a computer.

The Bit

                    

                        The smallest unit of data. A switch that is either OFF (0) or ON (1).
                    

                    

                        

                            Math: Value = bit * 2position
                        

                    

                


                

                    

                        
                    

                    
The Byte

                    

                        A group of 8 bits. This is the standard chunk size for computer memory.
                    

                    

                        

                            Range: 0 to 255 (28 combinations)
                        

                    

                


                

                    

                        
                    

                    
Overflow

                    

                        What happens if you add 1 to 255? It runs out of room and wraps back to 0. This is a common bug
                        source.
                    

                    

                        

                            Formula: (value + 1) % 256
                        

                    

                


                

                    

                        
                    

                    
Bit Shifting (<< and>>)

                    

                        Moving all bits to the left is an ultra-fast way to multiply by 2. Moving right divides by 2
                        (floored).
                    

                    

                        

                            Left (<<):< /span> 0010 (2) -> 0100 (4)
                        

                        

                            Right (>>): 0100 (4) -> 0010 (2)
                        

                    

                


                

                    

                        
                    

                    
MSB & LSB

                    

                        MSB (Most Significant Bit) is the leftmost bit (holds the most value, 128).
                        LSB is the rightmost (value 1).
                    

                

            

        


        

            
TL;DR

            

                A Register is temporary, super-fast storage located directly on the CPU. It uses binary (bits) to
                represent numbers. Computers manipulate these bits using logic operations like shifts and adds. When
                numbers get too big for the register, they "overflow" and wrap around.

Challenge: Break the Model

                    

                        

                            Try to create the number 256. You can't. Why? Because 8 bits can only hold
                            256 values (0 to 255). To store 256, you would need a 9th bit (or a 16-bit
                            register).
